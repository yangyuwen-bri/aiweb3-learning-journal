## Privacy Rules

This repo is intended to be public proof-of-work. Do not commit:

- API keys, bearer tokens, GitHub tokens, WCB secret keys, or `.env` files
- wallet seed phrases, private keys, keystore files, or recovery phrases
- unreleased meeting links, private contact details, or other people's personal data
- production credentials, admin screenshots, or non-public platform data

Any WCB Agent API key should stay in a local environment variable such as
`WCB_AGENT_SECRET_API_KEY`.

## Structure

Week 1 task 2 required structure:

- `notes/`: course notes and concept summaries
- `prompts/`: prompts, agent instructions, and reusable prompt patterns
- `demos/`: small demos, screenshots, and prototype records
- `logs/`: learning agent logs and weekly proof-of-work logs
- `resources.md`: links and references collected during learning

Extended learning-agent structure:

- `profile.md`: learner profile and preferences
- `learning-plan.md`: lightweight plan by path and week
- `daily/`: daily learning notes and check-in drafts
- `tasks/`: task notes, evidence, and review status
- `experiments/`: AI x Web3 demos, scripts, screenshots, and logs
- `handbook-feedback/`: Handbook issues, unclear concepts, fixes, and suggestions
- `hackathon/`: project ideas, problem statements, and validation notes
- `submissions/`: WCB / check-in submission records and public proof links
- `templates/`: reusable note templates
