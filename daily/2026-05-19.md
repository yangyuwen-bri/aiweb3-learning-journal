## Learning Notes

Current understanding before / during today's session:

- Prompt: one-time instruction or input to an AI model.
- Workflow: a repeatable process with steps, checks, outputs, and handoff points.
- Agent: an AI-assisted system that can use tools, maintain context, update files, and help complete a workflow over time.

For my AI x Web3 School learning repo, the Learning Agent should help with:

- reading course material and Handbook pages
- turning vague tasks into daily action plans
- drafting notes and check-ins
- maintaining repo structure
- organizing proof-of-work
- tracking Handbook feedback

The Learning Agent must pause before:

- GitHub push
- WCB submission
- wallet signature
- transfer
- token approval
- contract deployment or write action
- handling any private key, seed phrase, API key, or secret
