# Demos

Small prototypes and demo records.

Examples:

- AI-generated concept card
- CLI helper
- simple web page
- transaction explainer
- Remix / testnet contract interaction record

## Current Demos

- `foundations-map/`: AI x Web3 基础能力地图，用于概念复习和签名前自测。
- `ai-concept-coach/`: AI 概念复述训练器，用 `glm-5.1` 帮学习者生成解释、完成复述练习，并给出反馈和学习笔记草稿。

Each demo should include what was generated, what was reviewed manually, and what evidence proves it worked.
