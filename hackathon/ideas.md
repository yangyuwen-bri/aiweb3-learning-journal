# Hackathon Ideas

## 2026-05-21 - AI x Web3 Application Directions

Today's session shifted my attention from broad AI x Web3 narratives to concrete infrastructure and safety problems.

## Idea 1: Wallet Action Explainer

Target user:

- Web3 beginners using MetaMask or smart wallets.

Pain point:

- Users often do not understand what a wallet signature, approval, transfer, or contract interaction will do.

AI component:

- Explain wallet actions in plain language.
- Generate pre-signature questions.
- Summarize risk factors.

Web3 component:

- Transaction hash, calldata, contract address, token approval, dApp origin, block explorer data.

Why it matters:

- The hardest part for beginners is not clicking the wallet button, but knowing what they are confirming.

## Idea 2: Testnet Transaction Reflection Coach

Target user:

- AI x Web3 learners completing testnet tasks.

Pain point:

- Learners can complete a transaction but still cannot explain hash, gas, block, from/to, or explorer status.

AI component:

- Turn transaction details into a learning note.
- Ask follow-up questions to check understanding.
- Generate proof-of-work drafts.

Web3 component:

- Testnet transaction hash, explorer data, wallet confirmation, gas and block height.

Why it matters:

- It converts mechanical task completion into actual understanding.

## Idea 3: AI Agent Permission Boundary Checker

Target user:

- Learners and builders using AI agents with Web3 workflows.

Pain point:

- People may not know which steps can be automated and which steps require human confirmation.

AI component:

- Classify steps by risk.
- Explain why signatures, approvals, transfers, and contract writes need human confirmation.
- Generate safer workflow plans.

Web3 component:

- Wallet signatures, token approvals, smart contract writes, transaction broadcasting.

Why it matters:

- AI agents become more useful only when their boundaries are explicit.

## Idea 4: AI x Web3 Project Matrix

Target user:

- Beginners trying to understand AI x Web3 projects.

Pain point:

- Project lists are hard to remember and do not explain where each project fits.

AI component:

- Categorize projects by infrastructure layer, agent wallet, chain analytics, wallet security, DeFi risk.
- Generate comparison notes.

Web3 component:

- Protocols, wallets, dApps, analytics tools, security tools.

Why it matters:

- It helps learners ask “which concrete problem does this project solve?” instead of only following narratives.
