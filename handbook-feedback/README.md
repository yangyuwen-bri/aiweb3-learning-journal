# Handbook Feedback

Use this folder to collect issues, unclear concepts, outdated links, typo fixes, structure suggestions, and missing examples from the AI x Web3 School Handbook.

Source Handbook: https://aiweb3.school/zh/handbook/

## Feedback Flow

1. Capture: write a short note when a page is confusing, outdated, incomplete, or especially useful.
2. Triage: classify as typo, concept clarity, outdated resource, missing example, structure, translation, or new resource.
3. Draft: include the Handbook page URL, current wording or location, problem, suggested fix, and source.
4. Publish: commit the note to this public repo after checking it contains no private data.
5. Upstream: when ready, open the Handbook GitHub edit link or issue / PR at https://github.com/lxdao-official/aiweb3school.

## Naming

Use:

```text
YYYY-MM-DD-short-topic.md
```

Example:

```text
2026-05-18-wallet-signature-clarity.md
```
