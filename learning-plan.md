## Week 1 Objective

Build the common language and first operating loop for AI x Web3:

1. Understand the boundary between LLM, prompt, workflow, agent, tools, tracing, guardrails, and human-in-the-loop.
2. Understand Web3 account, wallet, address, seed phrase, private key, signature, gas, testnet, block explorer, and contract interaction basics.
3. Complete a minimum AI x Web3 flow:
   AI output -> human review -> wallet confirmation -> testnet execution -> block explorer verification.
4. Record all proof-of-work in this repo.

## Challenge Path

Choose one small prototype:

- Transaction explainer: AI explains a testnet transaction and records verification steps.
- Contract interaction assistant: AI drafts a read/write plan, learner reviews and executes manually.
- Learning agent workflow: AI drafts tasks, creates notes, and pauses before any wallet or WCB write action.

Every prototype must document:

- what the AI generated
- what the human reviewed
- where the system paused for confirmation
- transaction hash / contract address / screenshot / link, if any
- failure and correction notes

## Weekly Deliverables

- Learning Agent setup record and repo README
- At least one agent-assisted learning or coding log
- Testnet transaction hash or contract address when ready
- Minimum AI x Web3 experiment note
- Handbook feedback entries for unclear or outdated content
