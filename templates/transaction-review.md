# Transaction / Signature Review Checklist

Purpose: before signing any Web3 action, slow down and identify what is being authorized.

- Date:
- Network:
- Wallet account:
- Website / app:
- Action type:

## 2. Human Confirmation

- [ ] I know which network I am using.
- [ ] I know whether this is mainnet or testnet.
- [ ] I know which account is signing.
- [ ] I understand what this action will do.
- [ ] I checked whether assets, approvals, or contract writes are involved.
- [ ] I did not expose seed phrase, private key, or recovery phrase to any AI tool or website.
